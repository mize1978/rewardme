# 1. 確定事項

## 1-1. 成長システム：交互成長

タスク達成によって、**リボンちゃんとその世界が交互に成長する**。

```
① BASE   × たまご
      ↓ キャラクター成長
② BASE   × ベビー
      ↓ 世界の成長
③ COZY   × ベビー
      ↓ キャラクター成長
④ COZY   × リボンちゃん
      ↓ 世界の成長
⑤ DELUXE × リボンちゃん
      ↓ キャラクター成長
⑥ DELUXE × プリンセス
```

- キャラクター進化＝**大きな節目**（進化演出あり）
- 部屋の成長＝**節目の間に訪れる静かな変化**（演出を足さない）
- キャラクター進化の既存しきい値 **10 / 20 / 40 を維持**
- 部屋の成長しきい値は**未確定**（→ 2-1）

**採用理由**: 全3色の素材を数えたところ、4枚ではなく6枚あり、
組み合わせが完全な交互構造になっていた。素材が既に設計を語っていた。

## 1-2. HOMEモデル：HOME と ROOM COLLECTION の分離

| | HOME | ROOM COLLECTION |
|---|---|---|
| 正体 | 育てているリボンちゃんのお部屋 | 集めたテーマルーム |
| 入手 | **タスクによってのみ成長** | コインで購入 |
| 販売 | **売っていない・買えない・ガチャから出ない** | ショップで販売 |
| 喪失 | **失われない** | — |
| 使用中 | — | キャラの成長段階は維持される |

- **HOMEは所有物ではなく、RewardMeの進行そのもの。**
- テーマ部屋を使用中もHOMEの成長状態は裏で維持され、**いつでも帰れる**。
- **40タスクまでテーマ部屋をロックしない。** 育成途中から「自分の好きな部屋で暮らす」遊びを許す。

## 1-3. 経済の原則（憲法）

1. **努力による成長（リボンちゃん / HOME）は、コインでは買えない。**
   - 400コイン持っていてもプリンセスにはなれない。ここがHOMEの格。
2. **コインは「頑張ったあと、自分でごほうびを選ぶためのもの」。**
   - 成長＝自動報酬（選べない・買えない）
   - コイン＝選択報酬（何に変えるか自分で決める）
3. **1タスク = 10コイン を経済設計の基準単位とする。**
   - 500コインの部屋 → 50タスク相当、として価値を判断する
   - ※「10」が適正かは調整可能。重要なのは**タスクを物差しの中心に置くこと**

## 1-4. 報酬の4系統

| 系統 | 内容 | 性質 |
|---|---|---|
| **GROWTH** | リボンちゃん / HOME | 努力の結果として自動的に起きる。選べない |
| **CHOICE** | ROOM COLLECTION / 家具・デコ / ガチャ由来 | コインで選ぶ |
| **ACHIEVEMENT** | バッジ | 「私はこれを達成した」という証 |
| **COLLECTION** | パズルイラスト / お手紙 | 「私はこれと出会って、集めた」という思い出 |

- ACHIEVEMENT と COLLECTION は似て非なるもの。**証と思い出**の違い。
- **ミニゲームは報酬カテゴリではない。** PLAY という「行動」。
  何をくれるかはゲームごとに設計する。

## 1-5. ミニゲームの役割

| ゲーム | 役割 | 主役 | コイン |
|---|---|---|---|
| リボンパズル | **COLLECT** | 12枚のイラストが集まること | 副報酬 |
| リボンポーション | **CHALLENGE** | 最高到達Stage | 副報酬 |
| リボンキャッチ / リボンマッチ | **BREAK / SCORE** | 遊ぶこと＋自己ベスト | 副報酬 |
| 5枠目 | **VACANT** | （役割を与えない） | — |

- **ミニゲームは「コインを稼ぐ場所」ではない。** コインがもらえてもいいが、
  **遊ぶ理由そのものをコインにしない。**
- キャッチ／マッチには収集・育成を**追加しない**。何も背負っていない遊びがあってよい。

## 1-6. パズルイラスト12種の扱い

- **入手経路は変更しない**（パズルのクリア数で解放）
- **ショップ販売しない。コインでも買えない。**
- ただし**パズル画面の中に閉じ込めず、RewardMe全体のCOLLECTIONへ昇格**させる
- 理由: 80回クリアして得た人と、5タスクで買った人が同じものを持つのは、
  ACHIEVEMENT で禁止したことと同じ構造になる

## 1-7. 5枠目（旧リボンクエスト）

- **リボンクエストという仕様は存在しなかった**（→ 3-6 の調査結果）
- したがって**旧構想を守る義務はない**
- 5枠目は「リボンクエストを完成させる席」ではない。
  既存の盤面に手作り感があり作品全体の見栄えに合わないなら、
  **まったく別の、見栄えのいいゲームへ置き換えてよい**
- ただし何を作るかは、既存4ゲームと全体設計を整理したあと

## 1-8. ガチャ・ショップの役割分担

| システム | 役割 |
|---|---|
| タスク・育成 | 成長。リボンちゃん＋HOMEが育つ |
| ショップ | **選択**。欲しいテーマ・家具をコインで確実に買う |
| ガチャ | **偶然のごほうび**。ショップでは買えない特別なものが出る |
| バッジ | 記録。何を達成したかの証 |
| デコ | 自己表現。手に入れたものを使って暮らしを自分好みにする |

- **ガチャとショップの商品重複をやめる。** 通常テーマ部屋・通常家具はショップへ。
- ガチャの中身は未定（→ 5-2）

## 1-9. ゲームセンター改修の方針

- **報酬額から触らない。** まず「語り方」を直す。
- ロビー見出し「毎日遊んでコインをゲットしよう！」を変更する
- 各カードの主役を、コイン額から役割へ移す
  - パズル →「あと○回で新しいイラスト」（COLLECTION進捗）
  - ポーション →「BEST Stage ○ / 次はStage ○」（CHALLENGE）
  - キャッチ／マッチ →「BEST ○○」（SCORE）
  - コイン表示は**副情報へ降格**
- バックエンドをほぼ変えずに意味が変わる可能性が高い

# 3. 調査で判明した事実

## 3-1. BLUEに「成長する部屋」の実装は存在しなかった
`room_blue.png` と `room_blue_royal.png` はショップの別商品2件（FREE / SUPER 1200）。
部屋は `current_room_bg` のみで決まり、`ribbon_stage` を一切参照していなかった。

## 3-2. 段階の刻みが3種類バラバラに存在していた
- `ribbon_stage`（稼働中）: 4段階（0/10/20/40）
- 新素材の設計: 3段階（BASE/COZY/DELUXE）
- 成長ストリップ（ダミー）: 6段階（0-10/11-30/…）
→ 稼働中の4段階を正とし、BASEが s1・s2 の2枚を担当する形で整理した。

## 3-3. 部屋素材は3色とも6枚あり、完全な交互構造だった
PINK は7枚（BASE×リボンちゃん が追加で存在）、BLUE / PURPLE は6枚。
3色すべてで ①〜⑥ の鎖が成立する。

## 3-4. コイン経済の実測値

**収入**
| プレイスタイル | 内訳 | 1日 | 1週 |
|---|---|---|---|
| 控えめ | タスク3個＋デイリーBOX | 70 | 490 |
| 標準 | タスク5個＋パズル1回＋BOX | 190 | 1,330 |
| やり込み | タスク10個＋ゲーム全部＋BOX | 640 | 4,480 |

- デイリーBOXの期待値 **40コイン/日**
- **やり込み時、収入の78%がミニゲーム由来。タスクは16%。**
- パズル 100×3回=300 は **タスク30個分**

**支出**
- 有料部屋12種 8,500 ＋ 家具8種 305 ＝ **全コンプ 8,805コイン**
- 標準プレイで **46日**、やり込みで **14日** で買うものが尽きる

**タスク換算での歪み**
- 成長物語の全長 = 40タスク
- 桜ルーム 500コイン = **50タスク**（成長物語より高い）
- ロイヤル系 1200コイン = **120タスク**（成長物語3周分）
- 家具は全8種で30タスク（部屋1つより安い）
- **5〜10タスク帯（50〜100コイン）が完全に空白**

## 3-5. ガチャとショップが同じ商品を売っている
ガチャ排出16種のうち **10種が部屋背景**、その10種は**全てショップにも並んでいる**。
さらに排出の **45%がコイン（30/50/100）** で、1回50コインに対し
ガチャがコインの回収装置になっていない。

## 3-6. リボンクエストの仕様は存在しない
初出コミット `59465b7`（ポーション追加＋ロビー改装）の本文に
「Add リボンクエスト **coming-soon card** with quest_bg.png illustration」とのみ記載。
Git履歴・開発記録・README のいずれにも設計は残っていない。
カードの「リボンちゃんと一緒に冒険の旅へ出よう！」はプレースホルダ文言。

## 3-7. ミニゲームは4種＋空席1。4種とも累積記録をDBに持つ
| ゲーム | 制限 | 報酬 | DBの記録 |
|---|---|---|---|
| パズル | 1日3回 | 一律100 | `puzzle_clears_count` / `selected_puzzle_id` |
| ポーション | 1日1回 | 50〜200（**到達段階で変動**） | `potion_game_high_stage` |
| キャッチ | 1日1回 | 20〜100（得点） | `tap_game_high_score` |
| マッチ | 1日1回 | 10〜100（得点） | `match_game_high_score` |

ポーションだけ「今日の出来」ではなく「**どこまで到達したか**」で報酬が決まる。

## 3-8. ゲームロビーのUIが4種を均している
- ページ見出しが **「毎日遊んでコインをゲットしよう！」**
- 全カードの最下段が同じ枠・同じ書式で**コイン額**（150 / 100 / 100 / 100）
- パズルの「クリア数」、ポーションの「最高Stage」は**小さな1行**に落ちている
- **イラストが集まることは画面のどこにも書かれていない**
→ バックエンドの役割の芽が、画面では全て「コイン自販機」に潰されている。

## 3-9. 既存資産の棚卸し（画像96点）
| 資産 | 数 | 現在の入手方法 | 備考 |
|---|---|---|---|
| パズルイラスト | **12種** | パズルのクリア数（0/5/10…80回） | 名前・解放条件とも設定済み |
| テーマ部屋 | 18種 | ショップ＋ガチャ | うち無料6件 |
| 成長ルーム | 6種×3色 | タスク | 売らない |
| 家具 | 8種 | ショップ | **7/8は画像なし（絵文字配置）** |
| お手紙 | 13通 | 条件で自動配信 | 読み物のコレクション |
| 称号 | 2種 | ガチャSSR | ほぼ死蔵 |
| マッチ駒 | 8種 | ゲーム内グラフィック | 素材として存在 |

**家具システムは完成品ではなくプロトタイプ**と見るのが正確。

## 3-10. UIとコードの食い違い（1件）
ポーションのロビー表示は「Stage5クリアで150コイン」だが、
実装は `potion_coins_for` により **stage6以上で200コイン**。表示が古い。

# 4. 却下した案

| 案 | 却下理由 |
|---|---|
| **キャラと部屋の完全同期** | 素材が6枚あり交互構造だった。同期だと変化が3回で打ち止め、部屋が独立した意味を持てない |
| **40タスクをショップ価格の上限にする** | HOMEが最上位なのは高価だからではなく**買えないから**。高額商品の存在自体はHOMEの価値を傷つけない |
| **テーマ部屋を成長完了後に解放** | RewardMeは40タスク終わるまで我慢して遊ぶゲームではない。**頑張る途中もかわいく遊べる**ほうがよい |
| **パズルイラストのショップ販売** | 80回クリアで得た人と5タスクで買った人が同じものを持つことになる |
| **ガチャ＝お土産という世界観づけ** | 「どこへ出かけたの？」という新しい設定が必要になる。世界設定を増やさない |

## 封印保存（将来やる可能性あり）
**窓の外モデル** — 部屋の構造はHOMEのまま固定し、テーマは窓の外の景色だけを変える案。
`成長 × テーマ` が掛け算になり両立するが、既存18部屋の絵が流用できず作り直しになる。
**今ではない。**

# 5. 候補（決定ではない）

## 5-1. ガチャのコイン排出廃止
コインは「頑張った結果として貯めるもの」であり、ガチャを
「コインを増やす場所」にしなくてよい。**廃止候補**。

## 5-2. ガチャの中身の方向性
ショップで値札が付いている商品ではなく、**ガチャでしか出会えないもの**。
候補として挙がった（**まだ作らない**）: 特別なデコ / 小物 / アクセサリー /
エフェクト / レア家具 / 季節物 / コレクションアイテム。

## 5-3. SHOPの棚を3〜4階層にする
| 棚 | 想定価格帯 |
|---|---|
| SMALL REWARD | 数タスクで届く小さなごほうび |
| DECOR / FURNITURE | 少し貯めて、自分らしくするもの |
| ROOM COLLECTION | ちゃんと貯めて手に入れる大きなごほうび |
| SPECIAL | かなり長く貯めて狙うもの（1200コイン級はここなら成立しうる） |

**今日は商品を増産しない。棚の設計だけ。**

## 5-4. その他
- ミニゲームの収入比率を下げてタスクの比重を戻す（数値は 2-4 で保留）
- パズルイラストをROOMに飾る / プロフィールにお気に入り設定
- 称号を ACHIEVEMENT 側へ移籍（2-5 の精査後）
